Product Backlog & User Stories

  • US-01 (2 Pts): As a Librarian, I want to add new books with ISBN, author, and category so the catalog stays updated.
  • US-02 (2 Pts): As a Student, I want to search and filter books in real time so I can check availability.
  • US-03 (3 Pts): As a Librarian, I want to issue available books to a student PRN with due dates.
  • US-04 (3 Pts): As a DevOps Engineer, I want an automated GitHub Actions CI/CD pipeline with Pytest, Flake8, and Vercel deployment.

Acceptance Criteria & Definition of Done

Acceptance Criteria (US-03: Issue a Book):

• Scenario 1: Given a book is marked Available, when issued to a student, status updates to Issued with borrower name.

• Scenario 2: Given a book is already Issued, duplicate issue requests are prevented.

Definition of Done (DoD):

1. Code adheres to PEP8 standards verified via flake8.

2. Automated unit tests pass 100% via pytest.

3. GitHub Actions CI/CD pipeline deploys cleanly to Vercel production.
